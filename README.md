## Program Description
This program models a real-world Jeepney object in Dart using core Object-Oriented Programming (OOP) concepts, including fields, methods, constructors, encapsulation, and lists.

## Features & Rubric Checklist
- **Class Definition:** `Jeepney` class with `route`, `capacity`, and `_fare` fields.
- **Constructor:** Parameterized constructor initializing field values upon object creation.
- **Encapsulation:** Private field `_fare` with getter and setter validation.
- **List Usage:** Stores multiple `Jeepney` objects in a `List<Jeepney>` collection.
